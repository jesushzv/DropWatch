|---|---|---|---|
| 2026-08-24 | `usedropwatch.com` is served by the Vercel project **`dropwatch`**; the duplicate `drop-watch` project is deleted — **executed and verified 2026-08-24** | Two projects were building this repo. The custom domain landed on `drop-watch`, which lacks `VITE_META_PIXEL_ID`, so the bundle it served had no Meta Pixel — ads would have optimised blind. `dropwatch` is the project named in CLAUDE.md and holds the pixel env var and deploy history | A second project is ever needed (staging, a separate marketing site) — then name it explicitly in CLAUDE.md rather than letting a stray link create it |
| 2026-08-29 | The landing page stays at the repo root; the full-stack app lives in `app/` and is **not** deployed | PR #16 put the app at the root and moved the landing page to `landing-page/`. The Vercel project `dropwatch` builds the repo root, so its preview served the bundled Express server as `text/plain` at `/` and 404'd `/landing-page/` — the live validation probe would have gone down mid-ad-spend, and the Express server cannot run on that static project at all | The probe resolves and the app has a host of its own — then the root can become whatever the product needs |
| 2026-08-29 | Where the DropWatch app is hosted is **deferred**, explicitly | The app needs a long-running Node process; Vercel's static project cannot provide one. Picking a host is an `/architecture` decision and the Architecture gate has never been run. Deciding it implicitly, as a side effect of a file move, is how the probe nearly went down | `/architecture` runs — before any attempt to deploy `app/` |
| 2026-08-29 | The app's MySQL schema is **on notice**, not accepted | `app/drizzle/schema.ts` is MySQL via `mysql2`, while the documented stack and the landing page's `dropwatch_leads` are Supabase Postgres with RLS on every table. The repo currently implies two engines. Nothing has been migrated, so the cost of choosing is still low | `/architecture` runs; whichever way it goes, record it here rather than letting the scaffold's default stand |
